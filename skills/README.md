# Ecosystem Skills Index

## Superpowers (Development Workflow)

| Skill | Description | When to Use |
|-------|-------------|-------------|
| `brainstorming` | Design phase before implementation | Before any creative work |
| `writing-plans` | Create implementation plans | After design approved |
| `subagent-driven-development` | Execute plans with subagents | During implementation |
| `test-driven-development` | TDD methodology | When writing code |
| `systematic-debugging` | Root cause analysis | When fixing bugs |

## CRISP-DM (Data Science)

| Skill | Description | Phase |
|-------|-------------|-------|
| `business-understanding` | Define objectives & success criteria | Phase 1 |
| `data-understanding` | Explore data sources & quality | Phase 2 |
| `data-preparation` | Clean, transform, feature engineering | Phase 3 |
| `modeling` | Train ML models & tune hyperparameters | Phase 4 |
| `evaluation` | Assess model against business objectives | Phase 5 |
| `deployment` | Production deployment & monitoring | Phase 6 |

## Usage

Invoke skills using the format:
- Superpowers: `superpowers:skill-name`
- CRISP-DM: `crisp-dm:skill-name`

Example:
```
Invoke the business-understanding skill to define project objectives.
```
